## Proposed Changes

We will build a Client-Side Single Page Application (SPA). This means all the processing (including PDF to image conversion and map drawing) happens in the browser, requiring no backend servers.

### 1. Technology Stack
- **Framework**: React (via Vite)
- **Styling**: Vanilla CSS with modern, rich aesthetics (Glassmorphism, dark/light sleek themes).
- **Canvas/Graphics**: `konva` and `react-konva` for interactive 2D graphics (drawing maps, selecting points, drawing dotted lines, rotating the chakra).
- **PDF Handling**: `pdfjs-dist` to parse PDFs in the browser and convert them to images for the canvas.
- **Hosting**: **Vercel** or **Netlify**. Both offer excellent, permanently free tiers for personal frontend projects.
